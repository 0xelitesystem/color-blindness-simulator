Color Blindness Simulator

Preview color-vision deficiencies

See how an image or a set of colors reads under the common color-vision deficiencies: protanopia, deuteranopia, tritanopia, and achromatopsia. Everything runs on a canvas in this page. Nothing is uploaded.

Drop an image here or click to choose a file
PNG, JPG, WEBP, GIF, or any format your browser can render
Accepts hex (#rgb or #rrggbb), rgb(...), or CSS color names.
All processing happens locally on a canvas. Images and colors never leave your browser.
